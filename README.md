# شجرة عائلة البوحسون - Albuhasson Family Tree
> **فخذ النواصر · آل جابر · قبيلة آل بوعينين**

المنصة الرقمية التفاعلية لشجرة وأنساب عائلة البوحسون الكريمة، مصممة بلغة **Apple Liquid Glass** الحديثة ولون الزمرد السعودي، وجاهزة للنشر التلقائي والمستمر على **GitHub Pages**.

---

## 🌟 مميزات المنصة

- 🌳 **شجرة عائلة تفاعلية (Interactive Tree):** تدعم السحب والتكبير والتصغير (Pan & Zoom) وإيماءات اللمس بالأصابع (Pinch to Zoom) للهواتف الذكية.
- 📱 **نمطان ديناميكيان للعرض:** التبديل الفوري بين المخطط الشجري الحر والمخطط الهرمي السلس المخصص للجوال.
- 📜 **مسار النسب وسلسلة الأجداد:** تتبع السلسلة الأبوية المتصلة صعوداً من أي فرد حتى الجد المؤسس حسن بن محمد بن جابر آل بوعينين.
- 👥 **دليل الأفراد والبحث الذكي:** بحث بالاسم واللقب والشهرة مع معالجة وتطبيع الحروف العربية والهمزات.
- 📊 **لوحة إحصائيات متقدمة:** تحليل شامل لنسب الذكور والإناث، الأحياء والمتوفين، عمق الأجيال، وأواصر المصاهرة التاريخية.
- 🔒 **لوحة تحكم المدير (Admin Dashboard):**
  - **اسم المستخدم:** `saad`
  - **كلمة المرور:** `33740`
  - تمكين إضافة وتعديل وحذف السجلات وإدارة النسخ الاحتياطية.
- 💾 **تخزين محلي مع استيراد وتصدير:** حفظ فوري على المتصفح (`localStorage`)، وتصدير/استيراد ملفات `JSON`، وتصدير جداول `CSV/Excel` متوافقة مع الحروف العربية.
- 🖨️ **طباعة وثائق رسمية:** تصدير وثيقة شجرة العائلة كملف PDF عالي الدقة.

## 🚀 النشر التلقائي على GitHub Pages (Automated CI/CD)

المشروع مزود بملف سير عمل تلقائي عبر **GitHub Actions** (`.github/workflows/deploy.yml`):

1. في مستودع GitHub الخاص بك، اذهب إلى:
   **Settings ➔ Pages**
2. في قسم **Build and deployment**:
   - اضبط **Source** على: `GitHub Actions`
3. بمجرد تفعيل هذا الخيار، سيقوم GitHub ببناء ونشر الموقع تلقائياً في كل مرة تتم فيها مزامنة أو تعديل للأكواد، وسيظهر رابط الموقع المباشر في تبويب **Pages**.
